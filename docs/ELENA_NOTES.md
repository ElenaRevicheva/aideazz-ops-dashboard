## Weekly Focus Rule

**Only one module in active build at a time.**

Do NOT simultaneously:
- Build site
- Configure outbound
- Install Instantly
- Design content system
- Handle remarketing

Single-module focus prevents burnout and half-finished work. "One module" = one Blueprint module (e.g. Website Rebuild, Attribution Capture), not one task. Week 2 can include both "port site" and "form" because both are part of Module 1.
