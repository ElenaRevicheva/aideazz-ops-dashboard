1. **Order:** Blueprint order; confirm with Manny before moving to the next module.
2. **Attribution from day one:** Form must capture UTM and landing URL from the start.
3. **Ownership:** Manny owns SiteGround, GTM, GA, Google Ads; Elena has admin/collaborator access.
4. **Communication:** WhatsApp daily or every other day (~8–9 AM CST).
5. **Blockers:** Use AI Architect Slack within a few hours if stuck.
6. **Content:** Start with 3–5 project photos/videos; don't wait for a full library.
